NAT & Port Address Translation (PAT)

Network Layer | Private Networks | Internet Connectivity

🌐 What is NAT?

NAT (Network Address Translation) is a technique used by a router or firewall to translate IP addresses between private and public networks.

NAT is commonly used to allow devices using private IPv4 addresses to communicate with the Internet using a public IPv4 address.

Simple Idea:

Private IP Address → NAT Router → Public IP Address → Internet

🎯 Why is NAT Used?

1 IPv4 Address Conservation

NAT allows many devices using private addresses to share one or more public IPv4 addresses.

2 Private Addressing

Internal devices can use private address ranges such as 10.0.0.0/8 and 192.168.0.0/16.

3 Internal Network Management

Internal addressing can be managed independently from the public Internet addressing scheme.

4 Address Translation

NAT modifies IP addressing information as packets move between private and public networks.

🔄 Types of NAT

1 Static NAT

Static NAT creates a permanent one-to-one mapping between a private IP address and a public IP address.

Private: 192.168.1.10
Public: 203.0.113.10

Useful when an internal server needs a consistent public address.

2 Dynamic NAT

Dynamic NAT maps private addresses to addresses selected from a pool of public IP addresses.

Private IP → Public IP Pool

3 PAT

PAT allows multiple private devices to share a single public IP address by using different TCP/UDP port numbers.

Also commonly called: NAT Overload

🚀 What is PAT?

Port Address Translation (PAT) is an extension of NAT that uses port numbers to distinguish different connections.

Multiple private devices can therefore share one public IPv4 address.

PC 1
192.168.1.10:5000
→
Public IP
203.0.113.10:30001
PC 2
192.168.1.11:5000
→
Public IP
203.0.113.10:30002
Key Idea:

Same Public IP + Different Port Numbers = Multiple Simultaneous Connections

📝 How PAT Works

1
A private computer sends a packet to an Internet server.
2
The NAT router receives the packet.
3
PAT changes the private source IP address to the router's public IP address.
4
PAT assigns a unique source port number.
5
The packet is sent to the Internet.
6
When the response returns, PAT uses the translation table to identify the correct internal device.

⚖️ NAT vs PAT

Feature NAT PAT
Full Form Network Address Translation Port Address Translation
Mapping IP address translation IP + Port translation
Public IP Usage May require multiple public IPs Many devices can share one public IP
Port Translation Not necessarily Yes
Common Name Address Translation NAT Overload
Main Benefit Translates private/public addresses Conserves public IPv4 addresses

🎯 Easy Way to Remember

  • NAT: Changes IP addresses.
  • PAT: Changes IP addresses + port numbers.
  • Static NAT: One private IP ↔ One public IP.
  • Dynamic NAT: Private IP ↔ Public IP from a pool.
  • PAT: Many private devices → One public IP using different ports.
Memory Trick:

NAT = IP Translation
PAT = IP + Port Translation
