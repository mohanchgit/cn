2. OSPF – Open Shortest Path First

OSPF is a link-state Interior Gateway Protocol (IGP) used to exchange routing information within an autonomous system.

Important OSPF Characteristics

Feature OSPF
Type Link-State IGP
Algorithm Shortest Path First (SPF)
Algorithm Basis Dijkstra
Metric Cost
Database Link-State Database (LSDB)
Design Supports hierarchical areas
Backbone Area 0

OSPF Operation

1. Discover neighbors.
2. Form OSPF neighbor relationships.
3. Exchange link-state information.
4. Build LSDB.
5. Run SPF.
6. Calculate best paths.
7. Install selected routes.

4. OSPF Areas and Hierarchical Design

Large OSPF networks can be divided into areas. Area 0 is the backbone area.
Memory Trick: Area 0 = Backbone

Other areas connect to the backbone through appropriate OSPF area-border functions.

5. OSPF DR and BDR

On certain multi-access networks, OSPF uses a Designated Router (DR) and Backup Designated Router (BDR) to reduce the number of full adjacency relationships.

Why?

Suppose 5 routers share one multi-access network. Without DR/BDR, the number of potential router-to-router relationships can grow quickly. DR/BDR helps organize OSPF adjacency and LSA exchange on such networks.

DR/BDR Animation

Key idea: DR and BDR are elected on network types where OSPF uses this mechanism. They are not a feature required on every OSPF network type.

6. BGP – Border Gateway Protocol

BGP is a path-vector routing protocol used primarily for exchanging routing information between Autonomous Systems (ASes).

What is an Autonomous System?

An Autonomous System (AS) is a network or collection of networks under a common routing administration and policy.

OSPF vs BGP Scope

OSPF

Primarily used inside an autonomous system.

IGP

BGP

Used for routing information exchange between autonomous systems.

EGP / Inter-domain routing protocol

BGP Key Characteristics

  • Path-vector protocol.
  • Uses attributes to support routing policy.
  • AS_PATH records the autonomous systems a route advertisement has traversed.
  • eBGP operates between different autonomous systems.
  • iBGP operates between BGP speakers within the same autonomous system.
  • Supports route advertisement and withdrawal.

8. BGP Path Selection

BGP does not simply select a route based on the fewest physical hops. BGP evaluates route attributes and local routing policy.

Important BGP Attributes

Attribute Purpose / Concept
AS_PATH Records the sequence of ASes in the route advertisement.
NEXT_HOP Identifies the next-hop information for reaching the advertised destination.
LOCAL_PREF Used within an AS to express preference among routes.
MED Can provide a preference signal between neighboring ASes.
COMMUNITY Provides a way to group routes for applying policy.

AS_PATH Example

Network: 203.0.113.0/24

AS 300
   |
   | Advertisement
   ↓
AS_PATH = 300

AS 200 receives:
AS_PATH = 300

AS 200 advertises to AS 100:

AS_PATH = 200 300
Loop Prevention Concept: An AS can reject a BGP route advertisement if its own AS number appears in the AS_PATH.

Simplified Route Comparison

Route AS_PATH Example Interpretation
Route A 200 300 Traverses AS 200 and AS 300
Route B 400 500 300 Traverses AS 400, AS 500 and AS 300
Important Teaching Point: Do not teach BGP as simply "choose the shortest AS_PATH." BGP route selection involves multiple attributes and policies, and the exact decision process depends on the implementation and configuration.

10. OSPF Cisco Configuration Example

Router(config)# router ospf 1

Router(config-router)#
network 192.168.1.0 0.0.0.255 area 0

Router(config-router)#
network 10.0.0.0 0.0.0.3 area 0
Interpretation: The router enables an OSPF process and associates the specified interfaces/networks with Area 0.

11. Basic BGP Configuration Example

Router(config)# router bgp 65001

Router(config-router)#
neighbor 10.0.0.2 remote-as 65002

Router(config-router)#
network 203.0.113.0 mask 255.255.255.0
Important: The exact BGP configuration depends on the network design, addressing, policy requirements, platform and whether the session is eBGP or iBGP.

12. OSPF vs BGP

Feature OSPF BGP
Type Link-State Path Vector
Primary Scope Within an AS Between ASes / inter-domain routing
Example Role Interior Gateway Protocol Inter-domain routing protocol
Algorithm / Method SPF / Dijkstra Path-vector and policy-based route selection
Metric / Attributes Cost Multiple path attributes and policies
Database LSDB BGP Routing Information Base and Adj-RIBs/RIBs conceptually
Hierarchy Areas Autonomous Systems
Loop Prevention Topology / SPF mechanisms AS_PATH is a key mechanism for inter-AS loop prevention
Typical Use Enterprise/campus internal routing Internet and inter-domain routing
