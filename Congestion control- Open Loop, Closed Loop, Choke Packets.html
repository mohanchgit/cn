1. What is Network Congestion?

Congestion occurs when the amount of traffic entering a network becomes greater than the network's ability to handle it.

Simple Example:

Imagine a road.

🚗 🚗 🚗 🚗 🚗 🚗 🚗 🚗 🚗
If too many vehicles enter the road, traffic slows down.

A computer network behaves similarly.

Network Congestion

  • Too many packets enter the network.
  • Routers may have limited buffer space.
  • Queues become longer.
  • Packet delay increases.
  • Packets may be dropped.
  • Retransmissions may increase traffic further.
Important: Congestion is a network-wide problem, whereas flow control primarily protects a receiver from a fast sender.

2. Effects of Congestion

Effect What Happens?
Delay Packets wait longer in queues.
Packet Loss Router buffers may overflow.
Reduced Throughput Less useful data is delivered per unit time.
Retransmissions Lost packets may be transmitted again.
More Congestion Retransmissions can add additional traffic.
Congestion Collapse: In severe cases, increasing offered traffic can result in very little useful throughput because the network spends much of its capacity handling overloaded traffic and retransmissions.

3. What is Congestion Control?

Congestion control consists of techniques used to prevent or reduce excessive traffic in a network.

Main Goal: Keep the network operating efficiently without allowing traffic to overload network resources.

5. Open-Loop Congestion Control

Open-loop congestion control attempts to prevent congestion before it happens.

There is no need to wait for the network to become congested before taking preventive action.

Examples of Open-Loop Techniques

  • Retransmission policy
  • Window policy
  • Acknowledgment policy
  • Discarding policy
  • Admission policy
Technique Idea
Retransmission Policy Avoid unnecessary retransmissions.
Window Policy Control how many packets can be outstanding.
Acknowledgment Policy Avoid excessive acknowledgments where appropriate.
Discarding Policy Discard less important traffic when necessary.
Admission Policy Do not allow new traffic when resources are insufficient.

7. Closed-Loop Congestion Control

Closed-loop congestion control allows the network or endpoints to detect congestion and then take corrective action.

Closed Loop = Feedback

Send Traffic → Network → Detect Congestion → Feedback → Reduce Traffic

Three Basic Steps

  1. Monitor the network.
  2. Detect congestion.
  3. Take corrective action.

Examples

  • Backpressure
  • Choke packets
  • Implicit signaling
  • Explicit signaling

9. What is a Choke Packet?

A choke packet is a control message generated by a router when it detects congestion.

The router sends the choke message back toward the source and asks the source to reduce its transmission rate.

Simple Example


Sender              Router              Receiver

  |                   |                    |
  | ---- DATA ------> |                    |
  | ---- DATA ------> |                    |
  | ---- DATA ------> |                    |
  | ---- DATA ------> |                    |
  |                   |                    |
  |                   | CONGESTION!       |
  |                   |                    |
  | <--- CHOKE -------|                    |
  |                   |                    |
  | REDUCE RATE       |                    |
  |                   |                    |

Step Action
1 Sender sends packets.
2 Router receives heavy traffic.
3 Router detects congestion.
4 Router generates a choke packet.
5 Choke packet travels toward the source.
6 Source receives the congestion notification.
7 Source reduces its transmission rate.

12. Backpressure

Backpressure is another closed-loop congestion control technique.

When a router becomes congested, it can signal the previous router to slow down. That router can then signal the previous router, and so on. 


R1 → R2 → R3 → R4

        R3 congested
             ↑
             |
        Slow down R2
             ↑
             |
        Slow down R1
Key Idea: Backpressure moves congestion information backward toward the source.

13. Implicit Signaling

In implicit signaling, the sender does not receive a special congestion message. Instead, it infers congestion from network behavior.

Possible Indicators

  • Increased delay
  • Packet loss
  • Timeouts
  • Duplicate acknowledgments
TCP congestion control can use signals such as packet loss, duplicate ACKs, and increasing RTT to infer network conditions.

14. Explicit Signaling

In explicit signaling, a network device explicitly communicates congestion information to the sender or receiver.

Example: A router can mark packets or generate a control message to indicate congestion.
Signaling Meaning
Implicit Sender infers congestion.
Explicit Network explicitly indicates congestion.

19. Interview Questions & Answers

Q1. What is congestion control?

Congestion control is the set of techniques used to prevent or reduce network congestion by regulating traffic entering the network.

Q2. What is open-loop congestion control?

Open-loop congestion control attempts to prevent congestion before it occurs. It generally does not rely on congestion feedback to initiate the preventive policy.

Q3. What is closed-loop congestion control?

Closed-loop congestion control detects congestion and uses feedback to take corrective action.

Q4. What is a choke packet?

A choke packet is a congestion-control message generated by a router to inform the source that it should reduce its transmission rate.

Q5. What is backpressure?

Backpressure propagates congestion information backward through the network so upstream devices reduce their traffic.

Q6. What is implicit signaling?

The sender infers congestion from network behavior such as packet loss, delay, duplicate ACKs, or timeouts.

Q7. What is explicit signaling?

A network device explicitly communicates congestion information to endpoints, for example by marking packets or using a control message.

Q8. What is the difference between flow control and congestion control?

Flow control prevents a sender from overwhelming a receiver, while congestion control regulates traffic to avoid overwhelming the network.

Q9. What is the easiest way to remember Open Loop and Closed Loop?

OPEN LOOP = Prevent

CLOSED LOOP = Detect → Feedback → Correct

Q10. What happens after a choke packet reaches the source?

The source is expected to reduce its transmission rate to help relieve the congestion.
