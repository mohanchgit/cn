2. Distance Vector Routing

Definition: Distance Vector is a routing approach in which a router maintains information about destinations and the distance to those destinations, and learns routing information from neighboring routers.

Simple Idea

Distance

How far is the destination according to the routing metric?

Vector

Which direction or next hop should be used?

Neighbor

Routers exchange routing information with neighboring routers.

Update

Routing information is updated according to the protocol's rules.

Basic Formula

New Distance = Distance to Neighbor + Neighbor's Distance to Destination

Example:
Router A → Router B = 1 hop
Router B → Network X = 2 hops
Therefore: A → X = 1 + 2 = 3 hops

Key Characteristics

  • Routers communicate with neighbors.
  • Routing information is based on a metric.
  • Traditional RIP uses hop count.
  • Routing tables are periodically or event-driven updated according to the protocol.
  • Distance-vector protocols can experience convergence problems.

4. RIP – Routing Information Protocol

RIP is a distance-vector routing protocol that uses hop count as its routing metric.

RIP Basic Concepts

Feature RIP
Routing Type Distance Vector
Metric Hop Count
Maximum usable hop count 15
Hop count 16 Considered unreachable
IPv4 Version RIPv1 / RIPv2
IPv6 Version RIPng

Example

R1 → R2 → R3 → R4 → LAN

RIP calculates: 4 hops

Cisco RIP Example

Router(config)# router rip
Router(config-router)# version 2
Router(config-router)# network 192.168.1.0
Router(config-router)# network 10.0.0.0
Teaching Point: RIP is easy to understand and useful for teaching the distance-vector concept, but its hop-count metric and scalability limitations make it unsuitable for many modern large enterprise networks.

5. Count-to-Infinity Problem

Important Distance-Vector Problem: After a route failure, routers may temporarily advertise incorrect routes to each other and progressively increase the metric.

Example

Normal route: A → B → Network X
Metric = 1

How can it happen?

1. Network X becomes unreachable from B.
2. A may still have outdated information from B.
3. B may hear information from A and incorrectly believe A has a path.
4. Metrics can increase as incorrect information circulates.
5. Protocol mechanisms such as split horizon, route poisoning and triggered updates help reduce such problems.

Split Horizon

Split Horizon: A router does not advertise a route back through the same interface from which it learned that route.

Route Poisoning

Route Poisoning: A failed route can be advertised with an unreachable metric. For RIP, a metric of 16 represents unreachable.

6. Hierarchical Routing

Definition: Hierarchical routing organizes a large network into logical areas, regions, or levels so that routing information can be managed more efficiently.

Why Hierarchical Routing?

Scalability

Large networks are divided into manageable sections.

Smaller Routing Information

Routers do not always need detailed information about every individual network everywhere.

Reduced Overhead

Routing updates can be limited to appropriate areas.

Faster Management

Failures and changes can often be contained within an area.

7. Distance Vector vs Link State

Feature Distance Vector Link State
Information Distance and direction toward destinations Topology/link-state information
Knowledge Primarily neighbor-based information More complete topology information within its scope
Example RIP OSPF
Algorithm Bellman-Ford family concept Dijkstra / SPF
Convergence Can be slower depending on protocol and topology Generally faster within suitable designs
Example Metric RIP: Hop count OSPF: Cost

8. Distance Vector vs Hierarchical Routing

Concept Main Idea
Distance Vector Routers learn route distance and next-hop information from neighbors.
RIP A distance-vector protocol using hop count.
Hierarchical Routing Network organization into areas or levels to improve scalability and manageability.
