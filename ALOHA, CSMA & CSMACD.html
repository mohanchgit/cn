ALOHA, CSMA & CSMA/CD

Data Link Layer | Medium Access Control Protocols

🌐 What is a Medium Access Control Protocol?

When many devices share the same communication medium, they need rules to decide when a device can transmit.

These rules help reduce collisions and improve the efficiency of the shared communication channel.

Basic Problem:

Many devices → One shared channel → Who should transmit?

📡 1. ALOHA

ALOHA is one of the earliest random-access protocols for shared communication channels.

A station can transmit when it has data. It does not first check whether another station is transmitting.

Simple Idea:

"I have data → I transmit."

If a collision occurs → wait a random time → retransmit.

🔵 Pure ALOHA

📦 Data Ready
📡 Transmit
💥 Collision?
⏳ Random Wait
🔄 Retransmit
Pure ALOHA allows transmission at any time.

Maximum theoretical throughput is approximately 18.4%.

🕐 Slotted ALOHA

Slotted ALOHA divides time into equal-sized slots. A station can begin transmission only at the beginning of a time slot.

🕐 Time Slot
📦 Prepare
📡 Transmit
💥 Collision
🔄 Retry
Maximum theoretical throughput of Slotted ALOHA is approximately 36.8%.

👂 2. CSMA – Carrier Sense Multiple Access

CSMA improves on ALOHA by requiring a station to listen to the communication channel before transmitting.

Simple Idea:

"Listen before you transmit."

🔄 Types of CSMA

1 1-Persistent CSMA

The station continuously senses the channel. When the channel becomes idle, it transmits.

Idea: Listen → Idle → Transmit immediately

2 Non-Persistent CSMA

If the channel is busy, the station waits for a random period before sensing again.

Listen → Busy → Random wait → Listen again

3 p-Persistent CSMA

Used with slotted channels. When the channel is idle, transmission occurs with probability p.

Idle → Transmit with probability p

💥 3. CSMA/CD – Collision Detection

CSMA/CD stands for Carrier Sense Multiple Access with Collision Detection.

It was historically used with shared, half-duplex Ethernet networks to detect collisions while transmitting.

Simple Idea:

Listen → Transmit → Detect Collision → Stop → Backoff → Retry

⏳ Binary Exponential Backoff

After a collision, CSMA/CD uses a backoff mechanism before attempting retransmission.

1
Collision occurs.
2
Transmission stops and a random waiting time is selected from an increasing range.
3
The station waits for the selected number of time slots.
4
The station attempts transmission again.

⚖️ ALOHA vs CSMA vs CSMA/CD

Feature ALOHA CSMA CSMA/CD
Channel Sensing No Yes Yes
Collision Handling Retransmission Depends on variant Detect and retransmit
Main Idea Transmit whenever needed Listen before transmitting Listen + Detect collision
Typical Historical Use Shared radio/data networks Shared communication media Shared half-duplex Ethernet
Collision Avoidance Low Better than ALOHA Detection after transmission begins

💡 Important Note About Modern Ethernet

CSMA/CD is mainly a historical Ethernet access method.

Modern switched Ethernet networks normally operate using full-duplex links, where collisions do not occur on the link. Therefore, CSMA/CD is generally not used on modern full-duplex switched Ethernet.

🎯 Easy Way to Remember

  • ALOHA: "Transmit first."
  • CSMA: "Listen before transmitting."
  • CSMA/CD: "Listen + transmit + detect collision."
Memory Trick:

ALOHA → Transmit
CSMA → Listen
CSMA/CD → Listen + Detect
