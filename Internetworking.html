2. What is Internetworking?

Internetworking is the process of connecting multiple networks so that devices in different networks can communicate using appropriate networking protocols.

Simple Example

Internetworking Goals

Connectivity

Allow different networks to communicate.

Routing

Determine paths between networks.

Scalability

Support increasingly large network environments.

Interoperability

Allow different network technologies to work together through common protocols.

3. Internetworking Devices

Device Main Function Typical Layer
Repeater Regenerates signals Physical
Hub Repeats traffic to ports Physical
Switch Forwards frames using MAC addresses Data Link
Router Forwards packets between IP networks Network
Gateway Can provide protocol/application-level interconnection depending on implementation Varies
Key Teaching Point: A switch primarily forwards frames within a LAN based on MAC addresses, while a router forwards IP packets between networks based on routing information.

4. Link-State Routing

Definition: In link-state routing, routers build and maintain information about the topology of the network within their routing scope. Each router can use this topology information to calculate shortest paths.

Distance Vector vs Link State

Distance Vector Link State
Primarily learns route information from neighbors. Builds a topology database from link-state information.
Example: RIP Example: OSPF
RIP uses hop count. OSPF uses cost.
Bellman-Ford family concept. Dijkstra / SPF algorithm.

Link-State Routing Process

Step 1: Discover neighboring routers.
Step 2: Determine local link information.
Step 3: Create link-state information.
Step 4: Flood the information within the routing scope.
Step 5: Build the Link-State Database.
Step 6: Run SPF calculation.
Step 7: Install selected routes in the routing table.

5. Link-State Advertisement (LSA)

An LSA carries link-state information used by OSPF routers to build a consistent topology database within the appropriate area.

LSA Flooding Animation

Ready. Click Flood LSA.

What is Being Distributed?

The information can describe items such as:

  • Router identity
  • Connected links
  • Link costs
  • Reachability information
  • Other information defined by the routing protocol and LSA type
Important: Link-state routing is based on a shared topology database, not simply on one neighbor telling another router the complete best path.

10. OSPF Overview

Type

Link-State Interior Gateway Protocol.

Algorithm

Shortest Path First (SPF), based on Dijkstra's algorithm.

Metric

Cost.

Database

Link-State Database.

Updates

Link-state information is distributed according to OSPF operation and flooding scope.

Areas

OSPF supports hierarchical organization using areas.

Basic OSPF Configuration Example

Router(config)# router ospf 1

Router(config-router)#
network 192.168.1.0 0.0.0.255 area 0

Router(config-router)#
network 10.0.0.0 0.0.0.3 area 0
Interpretation: The router process participates in OSPF and advertises/uses the specified networks in Area 0 according to OSPF operation.

11. Distance Vector vs Link State

Feature Distance Vector Link State
Example RIP OSPF
Information Distance and direction Link-state/topology information
Topology Knowledge More limited neighbor-based view Topology database within routing scope
Algorithm Bellman-Ford family concept Dijkstra / SPF
Metric Example RIP: Hop Count OSPF: Cost
Database Routing information LSDB
Convergence Can be slower depending on protocol Generally designed for faster topology convergence
Scalability Limited compared with modern large-network IGP designs Designed to scale through areas and topology databases
