Key Idea: Each OSI layer performs a specific networking function and communicates with the layer directly above or below it.
Seven Layers of the OSI Model
The layers work together to provide complete network communication.
Layer 7

Application

Provides network services directly to end-user applications.

Layer 6

Presentation

Handles data translation, encryption and compression.

Layer 5

Session

Establishes, manages and terminates communication sessions.

Layer 4

Transport

Provides end-to-end delivery and transport reliability.

Layer 3

Network

Provides logical addressing and routing between networks.

Layer 2

Data Link

Provides framing, MAC addressing and link-level error control.

Layer 1

Physical

Transmits raw bits through the physical medium.

Mnemonic: All People Seem To Need Data Processing
Layer 7 — Application Layer
Provides services that network applications use to communicate.

HTTP / HTTPS

Used for web communication between clients and servers.

FTP

Supports file transfer between network systems.

SMTP

Supports email message transfer.

DNS

Resolves domain names into network addresses.

Telnet / SSH

Provides remote access functionality.

User Interaction

Closest OSI layer to the end-user applications.

PDU: Data / Message
Layer 6 — Presentation Layer
Ensures that data exchanged between systems is represented in a usable format.

Translation

Converts data between different representation formats.

Encryption

Provides data transformation for confidentiality.

Decryption

Converts protected data back into usable information.

Compression

Reduces the amount of data that needs to be transmitted.

Data Formats

Examples include character encoding and structured representation formats.

Example

JPEG, MPEG, ASCII, Unicode and encryption formats are commonly associated conceptually with this layer.

Layer 5 — Session Layer
Manages communication sessions between applications.

Session Establishment

Initiates communication sessions between applications.

Session Management

Coordinates communication during an active session.

Session Termination

Properly closes a communication session.

Dialog Control

Coordinates which side communicates and when.

Synchronization

Provides synchronization points for long communication sessions.

Example

Session-oriented communication mechanisms can use concepts associated with this layer.

Layer 4 — Transport Layer
Provides end-to-end delivery between processes running on network devices.

Segmentation

Divides application data into manageable transport units.

Flow Control

Coordinates the rate of data transmission between endpoints.

Error Control

Supports reliable delivery through mechanisms such as acknowledgements and retransmission.

Port Addressing

Identifies the source and destination application processes.

TCP

Connection-oriented and reliable transport protocol.

UDP

Connectionless transport protocol with low overhead.

PDU: Segment / Datagram
Layer 3 — Network Layer
Responsible for logical addressing and routing packets between networks.

Logical Addressing

Uses logical addresses such as IPv4 and IPv6 addresses.

Routing

Determines suitable paths for packets across interconnected networks.

Packet Forwarding

Routers forward packets toward their destinations.

IPv4

Uses 32-bit logical addresses.

IPv6

Uses 128-bit logical addresses.

Device

Routers primarily operate at this layer.

PDU: Packet
Layer 2 — Data Link Layer
Provides node-to-node delivery over a local communication link.

Framing

Organizes network-layer packets into frames.

MAC Addressing

Uses physical addresses for local network delivery.

Error Detection

Detects transmission errors using mechanisms such as CRC.

Flow Control

Coordinates data transmission between directly connected nodes.

Ethernet

Common Layer 2 LAN technology.

Switch

Ethernet switches primarily operate at the Data Link Layer.

PDU: Frame
