IP Addressing, IPv4 & IPv6

Network Layer | Logical Addressing

🌐 What is IP Addressing?

An IP address is a logical address assigned to a device connected to a network.

It helps the Network Layer identify the source and destination of packets.

Simple Example:
Just as a postal address identifies a house, an IP address identifies a device or network interface in a computer network.

🔢 IPv4 – Internet Protocol Version 4

IPv4 uses a 32-bit address. It is normally written as four decimal numbers separated by dots.

Example:

192.168.1.10

Each number is called an octet.

IPv4 Structure

192
8 bits
168
8 bits
1
8 bits
10
8 bits

8 bits + 8 bits + 8 bits + 8 bits = 32 bits

📚 Important IPv4 Address Concepts

1 Network Address

Identifies the network to which a device belongs.

Example: 192.168.1.0/24

2 Host Address

Identifies a particular device within a network.

Example: 192.168.1.10

3 Subnet Mask

The subnet mask separates the network portion from the host portion of an IPv4 address.

Example: 255.255.255.0

4 Default Gateway

The default gateway is normally the router interface used to reach other networks.

Example: 192.168.1.1

🚀 IPv6 – Internet Protocol Version 6

IPv6 was developed to overcome the limited address space of IPv4.

IPv6 uses a 128-bit address.

Example IPv6 Address:

2001:0db8:85a3:0000:0000:8a2e:0370:7334

IPv6 Address Structure

2001
0db8
85a3
0000
0000
8a2e
0370
7334

8 groups × 16 bits = 128 bits

⭐ Important IPv6 Features

1 Larger Address Space

IPv6 provides 128-bit addresses, creating an extremely large number of possible addresses.

IPv4 → 32 bits
IPv6 → 128 bits

2 Hexadecimal Notation

IPv6 addresses use hexadecimal digits separated by colons.

Example: 2001:db8::1

3 Address Compression

Consecutive groups of zeros can be compressed using ::.

Full:
2001:0db8:0000:0000:0000:0000:0000:0001

Compressed:
2001:db8::1

4 No Broadcast

IPv6 does not use traditional broadcast. Multicast and anycast mechanisms are used instead.

📐 CIDR – Classless Inter-Domain Routing

CIDR represents an IP address together with the number of network bits using slash notation.

Example:

192.168.1.0/24

/24 means that the first 24 bits represent the network portion.

🎯 Easy Way to Remember

  • IPv4 → 32 bits → Decimal → Dotted notation
  • IPv6 → 128 bits → Hexadecimal → Colon notation
  • IPv4 Example: 192.168.1.10
  • IPv6 Example: 2001:db8::1
Memory Trick:

IPv4 = 32-bit + Decimal + Dot
IPv6 = 128-bit + Hexadecimal + Colon
