Key Idea: Each layer performs a specific set of networking functions and works with the layers above and below it.
Four-Layer TCP/IP Model
The TCP/IP model is commonly represented using four conceptual layers.
Layer 4

Application Layer

Provides network services directly to applications. Examples include HTTP, DNS, FTP and SMTP.

Layer 3

Transport Layer

Provides process-to-process communication using protocols such as TCP and UDP.

Layer 2

Internet Layer

Provides logical addressing and routing using IP.

Layer 1

Network Access Layer

Handles local network delivery over technologies such as Ethernet and Wi-Fi.

Layer Interaction

Data moves down the stack at the sender and up the stack at the receiver.

Protocol Suite

TCP/IP is a collection of protocols rather than a single protocol.

Application Layer
The Application Layer provides protocols and services used by network applications.

HTTP / HTTPS

Used for communication between web browsers and web servers.

DNS

Translates domain names such as example.com into IP addresses.

FTP

Provides file transfer functionality between network hosts.

SMTP

Used for transferring email messages between mail systems.

SSH

Provides secure remote access to network systems.

DHCP

Automatically provides network configuration information to hosts.

Data Unit: Message / Data
Transport Layer
Provides end-to-end communication between applications running on network devices.
Connection-Oriented

TCP

Provides reliable, ordered and connection-oriented transport using acknowledgements, sequence numbers and retransmission mechanisms.

Connectionless

UDP

Provides a lightweight connectionless transport service with lower protocol overhead.

Port Numbers

Identify the source and destination application processes.

Internet Layer
The Internet Layer provides logical addressing and routing across interconnected networks.

IP

Provides logical addressing and packet delivery between network nodes.

IPv4

Uses 32-bit IP addresses such as 192.168.1.10.

IPv6

Uses 128-bit addresses and provides a vastly larger address space.

ICMP

Used for network control, diagnostic and error-reporting messages.

Routing

Routers examine IP information to forward packets toward their destinations.

Data Unit

The Internet Layer commonly handles IP packets or datagrams.

TCP/IP Protocol Stack — Summary
The TCP/IP architecture divides networking responsibilities into cooperating layers.
