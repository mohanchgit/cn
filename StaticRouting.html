2. What is Routing?

Routing is the process of selecting a path for packets to travel from a source network to a destination network.

Simple Example:
If Computer A wants to communicate with Computer B located in another network, the packet may have to travel through several routers. The routers use routing information to decide the next hop.

Basic Routing Process

Step 1

Source creates a packet.

Step 2

Packet reaches the default gateway/router.

Step 3

Router checks its routing table.

Step 4

Router selects the next hop.

Step 5

Packet continues toward the destination.

Important Terms

Source Destination Next Hop Routing Table Metric Interface Path

3. Static Routing

Static routing is a routing method in which the network administrator manually configures routes on the router.

Key Idea: The router does not automatically discover the route. The administrator explicitly tells the router where a destination network can be reached.

Example Cisco Command

Router(config)# ip route 192.168.3.0 255.255.255.0 10.0.0.2

Meaning:

  • 192.168.3.0 → Destination network
  • 255.255.255.0 → Destination subnet mask
  • 10.0.0.2 → Next-hop address

Advantages

  • Simple for small networks.
  • No routing protocol overhead.
  • Predictable path.
  • Can provide administrator-controlled routing.

Limitations

  • Manual configuration.
  • Does not automatically adapt to topology changes.
  • Large networks become difficult to maintain.

4. Dynamic Routing

Dynamic routing allows routers to automatically learn routing information by communicating through routing protocols.

Examples: RIP, OSPF, EIGRP and BGP are examples of routing protocols used in different network environments.

How Dynamic Routing Works

1. Discover

Routers discover neighboring routers.

2. Exchange

Routers exchange routing information.

3. Calculate

Routers calculate available paths.

4. Select

A route is selected according to the protocol's rules and metrics.

5. Update

Routing information can change when the topology changes.

Common Dynamic Routing Protocols

Protocol Category Main Concept
RIP Distance Vector Uses hop count as its routing metric.
OSPF Link State Uses link-state information and shortest-path calculation.
EIGRP Advanced Distance Vector Uses multiple route characteristics in its metric calculation.
BGP Path Vector Used for routing between autonomous systems.

5. Shortest Path Routing

Shortest-path routing attempts to select a path based on a defined cost or metric.

Important: "Shortest" does not necessarily mean physically shortest. It depends on the metric used by the routing algorithm.

Dijkstra's Algorithm

Dijkstra's algorithm is commonly associated with shortest-path computation in link-state routing concepts such as OSPF.

Example Network

Shortest path will appear here.

Step-by-Step Concept

Step 1: Set source distance = 0.
Step 2: Set all other distances = infinity.
Step 3: Select the unvisited node with the smallest distance.
Step 4: Update neighboring node distances.
Step 5: Mark the selected node as visited.
Step 6: Continue until the destination is reached.

6. Flooding

Flooding is a routing technique in which a packet is forwarded through multiple outgoing links, subject to mechanisms that prevent endless circulation.

Important: Without controls such as hop limits, sequence numbers, or duplicate detection, flooding can create many duplicate packets and excessive traffic.

Flooding Characteristics

  • Packet can be copied to multiple outgoing links.
  • Creates multiple possible paths.
  • Can be useful for information dissemination in certain network designs.
  • Can generate significant traffic.
  • Duplicate packet control is important.
  • Hop count / TTL can limit propagation.

7. Static Routing vs Dynamic Routing

Feature Static Routing Dynamic Routing
Configuration Manual Automatic through routing protocols
Route Updates Administrator updates routes Routers exchange routing information
Scalability Suitable for smaller/simple networks Better suited to changing and larger networks
Overhead Low routing-protocol overhead Routing protocol introduces processing and communication overhead
Failure Adaptation Requires manual changes unless supplemented by other mechanisms Protocols can recalculate routes according to their design
Administration More manual maintenance More automated
Examples ip route RIP, OSPF, EIGRP, BGP

When to Use?

Static Routing

  • Small networks
  • Stub networks
  • Specific controlled routes
  • Simple topology

Dynamic Routing

  • Large networks
  • Multiple paths
  • Changing topology
  • Automatic route learning

9. Think Like a Router

Suppose a packet has:

Source: 192.168.1.10

Destination: 192.168.3.20

The router checks the destination IP address and searches its routing table. It then selects the most appropriate matching route.

Basic Decision Process

  1. Read destination IP address.
  2. Search routing table.
  3. Find matching destination network.
  4. Select route according to routing-table rules.
  5. Determine next hop/interface.
  6. Forward packet.

10. Student Quiz

Q1. What is routing?

Correct! Routing determines how packets travel toward their destination.

Q2. Which routing method requires manual configuration?

Correct! Static routes are manually configured by an administrator.

Q3. Which protocol is a link-state routing protocol?

Correct! OSPF is a link-state routing protocol.

Q4. What metric does traditional RIP use?

Correct! RIP uses hop count as its routing metric.

Q5. Which algorithm is associated with shortest-path computation in link-state routing?

Correct! Dijkstra's shortest-path algorithm is associated with link-state routing.

Q6. What is a major problem with uncontrolled flooding?

Correct! Flooding can create many duplicate packets and excessive network traffic.
