Network Layer – Design Issues

Computer Networks | OSI Layer 3

🌐 What is the Network Layer?

The Network Layer is the third layer of the OSI model. It is responsible for delivering packets from a source network to a destination network.

The Network Layer mainly answers two important questions:

  • Where should the packet go?
  • Which path should the packet take?
Real-Life Example: When you access a website hosted in another country, your packets travel through several routers. The Network Layer helps determine how those packets reach the destination network.

⚙️ Major Design Issues of the Network Layer

1 Store-and-Forward Packet Switching

A router receives a packet and temporarily stores it before forwarding the packet to the next router.

Example: Router R1 receives the complete packet, checks it, and then forwards it to R2.

2 Services Provided to Transport Layer

The Network Layer provides communication services to the Transport Layer.

  • Connectionless service
  • Connection-oriented service
  • Packet delivery service
Example: IP provides a connectionless datagram service.

3 Routing

Routing determines the best path for packets from the source network to the destination network.

Routers use routing algorithms and routing tables to make path-selection decisions.

Examples: RIP, OSPF, IS-IS and BGP.

4 Forwarding

Forwarding is the actual process of moving a packet from an incoming interface to the correct outgoing interface.

Remember: Routing decides the path.

Forwarding sends the packet to the next hop.

5 Congestion Control

Congestion occurs when too many packets are present in the network and routers cannot process them fast enough.

  • Packet delay increases
  • Packets may be dropped
  • Network performance decreases
Example: A router receives packets faster than it can transmit them.

6 Quality of Service – QoS

QoS determines how different types of network traffic should be handled.

  • Bandwidth
  • Delay
  • Jitter
  • Packet Loss
Example: Voice and video applications generally require low delay and low jitter.

7 Addressing

Logical addressing identifies source and destination devices across different networks.

  • IPv4
  • IPv6
  • Network Address
  • Host Address
Example: 192.168.1.10 is an IPv4 address.

8 Internetworking

Internetworking allows different networks and network technologies to communicate with each other.

Example: A Wi-Fi network can communicate with a remote Ethernet network using IP.

9 Packet Fragmentation

Different networks may support different Maximum Transmission Units (MTUs).

In IPv4, a packet that is larger than the outgoing network's MTU may need to be fragmented.

Example: A large IPv4 packet may be divided into smaller fragments before transmission.

Routing vs Forwarding

Routing Forwarding
Determines the best path. Moves the packet to the next hop.
Uses routing algorithms. Uses the forwarding table.
Path calculation. Packet movement.
Examples: RIP, OSPF, BGP. Uses the selected outgoing interface.

🎯 Easy Way to Remember

The Network Layer mainly answers these questions:

  1. Who? → Addressing
  2. Where? → Destination Network
  3. Which Path? → Routing
  4. How to Send? → Forwarding
  5. How to Handle Traffic? → Congestion Control & QoS
One-Line Summary:
Address → Route → Forward → Manage Traffic
