1. Line Coding: Unipolar NRZ, NRZ-L and NRZ-I

Data = 01001110

Given data: 01001110

A. Unipolar NRZ

In Unipolar NRZ, 1 = positive voltage and 0 = zero voltage. The signal remains at that level for the entire bit period.

Unipolar NRZ levels: 0, +V, 0, 0, +V, +V, +V, 0

B. NRZ-L (Non-Return-to-Zero-Level)

For this example, use the common convention 0 = +V and 1 = −V. The signal level is determined directly by the bit value.

NRZ-L levels: +V, −V, +V, +V, −V, −V, −V, +V

C. NRZ-I (Non-Return-to-Zero Invert)

In NRZ-I, a 1 causes a transition/inversion at the beginning of the bit interval, while 0 causes no transition. Assume the initial signal level is −V.

Data: 0 1 0 0 1 1 1 0 Initial: −V Bit 1 = 0 → no transition → −V Bit 2 = 1 → transition → +V Bit 3 = 0 → no transition → +V Bit 4 = 0 → no transition → +V Bit 5 = 1 → transition → −V Bit 6 = 1 → transition → +V Bit 7 = 1 → transition → −V Bit 8 = 0 → no transition → −V
NRZ-I levels: −V, +V, +V, +V, −V, +V, −V, −V

4. OSI 7-Layer Data Transmission

Sender → Receiver
Application: User/application creates data such as HELLO.
Presentation: Translation, encryption/decryption and compression may occur.
Session: Establishes, manages and terminates the communication session.
Transport: Segments data and provides end-to-end delivery, reliability and flow control.
Network: Adds logical addressing and selects a route; creates packets.
Data Link: Adds MAC addressing and error-detection information; creates frames.
Physical: Converts frames to bits/signals and sends them through the medium.
Receiver: The reverse process occurs: Bits → Frame → Packet → Segment → Data → Application message.

6. Checksum Mechanism

Error Detection

Frames: 11001100, 10101010, 11110000, 11000011

Use 1's complement addition.

Step 1: 11001100 + 10101010 ----------- 1 01110110 End-around carry: 01110110 + 1 = 01110111 Step 2: 01110111 + 11110000 ----------- 1 01100111 End-around carry: 01100111 + 1 = 01101000 Step 3: 01101000 + 11000011 ----------- 00101011 1's complement: 00101011 ↓↓↓↓↓↓↓↓ 11010100
Checksum = 11010100

At the receiver, all four data frames plus the checksum are added using 1's complement arithmetic. If the result is 11111111, no error is detected; otherwise, an error is detected.

7. CRC Mechanism

Cyclic Redundancy Check

Data = 11101101 and Generator = 1001. Generator degree = 3, so append 3 zeros.

Data = 11101101 Append 3 zeros: 11101101000
Modulo-2 division: XOR is used instead of normal subtraction.
11101101000 ÷ 1001 Remainder = 011
CRC = 011
Transmitted codeword = Data + CRC = 11101101 + 011 = 11101101011

Receiver divides the received codeword by 1001. Remainder 000 means no error is detected; a non-zero remainder indicates an error.

Total bits = 7 + 4 = 11 bits. Parity positions are 1, 2, 4, 8.
