Unicasting • Multicasting • Broadcasting

Interactive Faculty Lecture & Student Learning Module

1. Learning Objectives

After completing this lecture, students should be able to:

Understand Unicasting

Explain one-to-one communication between a sender and a specific receiver.

Understand Multicasting

Explain one-to-many communication where the sender transmits to a selected group.

Understand Broadcasting

Explain one-to-all communication within an applicable broadcast domain.

Compare Communication Types

Identify differences in destination, packet delivery and bandwidth usage.

Faculty Opening Question: Imagine a teacher wants to send a message to one student, a selected group of students, or the entire class. Which communication method would be used in each case?

2. Communication Types

Unicast

One sender → One receiver

Example: A web client communicating with a web server.

Multicast

One sender → Selected group of receivers

Example: Multicast-based streaming or group communication.

Broadcast

One sender → All applicable receivers in the broadcast domain

Example: ARP request in an IPv4 LAN.

Communication Sender Receivers Basic Idea
Unicast 1 1 Specific receiver
Multicast 1 Selected group Group communication
Broadcast 1 All applicable hosts Everyone in broadcast domain

3. Unicasting

Definition: Unicasting is a communication method in which one sender sends data to one specific receiver.

Pattern: 1 → 1

Real-World Analogy

A teacher sends a private message to one particular student.

Network Example

Computer A wants to communicate with Server B.

Ready. Click Start Unicast.

Characteristics

  • One sender.
  • One specific receiver.
  • Uses a specific destination address.
  • Common for normal client-server communication.
  • Each separate receiver requires separate unicast communication.

Examples

  • Web browsing
  • SSH connection
  • FTP connection
  • Email communication
  • One computer communicating with another computer

4. Multicasting

Definition: Multicasting is a communication method where one sender sends data to a specific group of receivers that have joined the multicast group.

Pattern: 1 → Selected Group

Real-World Analogy

A teacher sends information only to students enrolled in a particular course.

Multicast Animation

Ready. Click Start Multicast.
Important Concept: The sender does not need to create an independent application-level copy for every member of the multicast group. The network can replicate traffic along branches where appropriate.

Examples

  • IPTV
  • Live streaming to subscribed receivers
  • Online group communication
  • Routing protocol group communication in appropriate designs

Multicast Addressing

In IPv4, multicast addresses belong to: 224.0.0.0 – 239.255.255.255

Example: 239.1.1.1

5. Broadcasting

Definition: Broadcasting is a communication method in which a sender transmits to all applicable hosts within the broadcast domain.

Pattern: 1 → All

Real-World Analogy

A teacher makes an announcement to the entire classroom.

Broadcast Animation

Ready. Click Start Broadcast.

IPv4 Broadcast

An IPv4 network can use a broadcast address to reach all hosts in the relevant broadcast domain.

Example: In a simple IPv4 LAN, an ARP request is sent as a broadcast so that the host owning the requested IPv4 address can respond.

Important Point

Routers normally do not forward ordinary IPv4 broadcasts between broadcast domains.

6. Unicast vs Multicast vs Broadcast

Feature Unicast Multicast Broadcast
Communication One-to-One One-to-Selected Group One-to-All in Broadcast Domain
Receivers One Selected receivers All applicable hosts
Addressing Specific destination Multicast group address Broadcast address
Example Web browsing IPTV / group streaming ARP request in IPv4 LAN
Bandwidth Can require separate traffic per receiver Efficient for selected groups when supported Can consume resources across the broadcast domain
Scope Specific destination Group members Broadcast domain
