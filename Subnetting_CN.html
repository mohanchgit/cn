🌐 What is Subnetting?

Subnetting is the process of dividing one large IP network into smaller logical networks called subnets.

It allows network administrators to use IP addresses more efficiently and organize networks into smaller segments.

Simple Example:

Instead of using one large network for an entire university, we can create separate subnets for:
  • CSE Department
  • ECE Department
  • Administration
  • Faculty Network

🎯 Why Do We Need Subnetting?

1 Efficient IP Usage

Subnetting reduces wastage of IP addresses by dividing networks according to actual requirements.

2 Smaller Broadcast Domains

Smaller subnets reduce broadcast traffic and improve network performance.

3 Better Security

Different departments can be placed into separate networks and controlled using routers, ACLs and firewalls.

4 Easier Management

Networks can be logically organized according to departments, locations or functions.

🧩 Network Portion and Host Portion

An IPv4 address contains two important portions:

  • Network portion – identifies the network.
  • Host portion – identifies a device within the network.
Network Portion
192.168.1
Host Portion
.10
Example: 192.168.1.10/24

/24 means the first 24 bits represent the network portion.

📐 Subnet Mask

A subnet mask determines which bits belong to the network portion and which bits belong to the host portion.

Network
255.255.255
Host
.0
Example:

IP Address: 192.168.1.10
Subnet Mask: 255.255.255.0
CIDR: /24

🧮 Important Subnetting Formulas

Number of Subnets

2n

n = number of borrowed host bits

Hosts per Subnet

2h − 2

h = remaining host bits

Block Size

256 − Subnet Mask Value
