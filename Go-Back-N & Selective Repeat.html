Go-Back-N & Selective Repeat

Data Link Layer | ARQ | Sliding Window Protocols

📡 What is ARQ?

ARQ (Automatic Repeat reQuest) is a reliability technique used in data communication to detect lost or damaged frames and request their retransmission.

Basic Idea:

Send Frame → Receive ACK → If Error/Loss → Retransmit

Two important sliding-window ARQ protocols are:

  • Go-Back-N ARQ
  • Selective Repeat ARQ

🪟 Sliding Window Concept

A sliding-window protocol allows a sender to transmit multiple frames before waiting for individual acknowledgments.

Example: Window Size = 4
0 Sent
1 Sent
2 Sent
3 Sent
4 Waiting
5 Waiting
6 Waiting
Window: A group of sequence numbers that the sender is currently allowed to transmit.

As acknowledgments arrive, the window moves forward — therefore it is called a sliding window.

🔵 1. Go-Back-N ARQ

In Go-Back-N, the sender can transmit multiple frames without waiting for an acknowledgment for every frame.

If one frame is lost or damaged, the sender retransmits that frame and all subsequent unacknowledged frames.

Easy Idea:

Frame 0 → Frame 1 → ❌ Frame 2 → Frame 3

Error at Frame 2

Retransmit: Frame 2 + Frame 3

🟢 2. Selective Repeat ARQ

In Selective Repeat, only the specific frame that is lost or damaged is retransmitted.

Easy Idea:

Frame 0 → Frame 1 → ❌ Frame 2 → Frame 3

Error at Frame 2

Retransmit only: Frame 2

⚖️ Go-Back-N vs Selective Repeat

Feature Go-Back-N Selective Repeat
Window Sliding window Sliding window
Error Handling Retransmits lost frame and subsequent unacknowledged frames Retransmits only lost/damaged frames
Receiver Buffer Limited / generally does not accept out-of-order frames Buffers correctly received out-of-order frames
Efficiency Lower when errors are frequent Higher when errors are frequent
Complexity Simpler More complex
Retransmission Multiple frames Individual frame
Receiver Storage Lower Higher

📚 Important Concepts

1 ACK

ACK means acknowledgment. It tells the sender that a frame has been received successfully.

2 NAK

NAK means negative acknowledgment. It can be used to indicate that a frame was not received correctly.

3 Timeout

If an expected acknowledgment does not arrive within a specified time, the sender can assume that retransmission may be necessary.

4 Sequence Number

Sequence numbers identify frames and help the receiver detect missing, duplicate, or out-of-order frames.

5 Sliding Window

The sender's transmission window moves forward as acknowledgments are successfully received.

🧠 Simple Classroom Example

Suppose the sender transmits: 0, 1, 2, 3

Frame 2 is lost.
GBN
Retransmits: 2 and 3
SR
Retransmits only: 2
Frame 3 can be buffered at the receiver.

🎯 Easy Way to Remember

  • Go-Back-N: "Error at Frame 2? Go back and resend Frame 2 onward."
  • Selective Repeat: "Error at Frame 2? Select and resend only Frame 2."
  • GBN: Simpler but may retransmit unnecessary frames.
  • SR: More efficient but requires more receiver buffering and greater protocol complexity.
Memory Trick:

GBN = Go Back + Resend Many
SR = Select + Resend One
