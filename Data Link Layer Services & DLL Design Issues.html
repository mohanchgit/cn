Data Link Layer
The Data Link Layer provides reliable node-to-node delivery over a physical link.

What is the Data Link Layer?

It is Layer 2 of the OSI model and is responsible for framing, physical addressing, flow control, error control and reliable delivery of frames between directly connected nodes.

Main services offered by the Data Link Layer to the Network Layer.
Service 01

Framing

Divides the network-layer packets into manageable units called frames.

Service 02

Physical Addressing

Service 03

Flow Control

Prevents a fast sender from overwhelming a slower receiver.

Service 04

Error Control

Detects and may correct damaged or lost frames using acknowledgements and retransmissions.

Stop-and-Wait

Sender transmits one frame and waits for an acknowledgement before sending the next frame.

Sliding Window

Multiple frames can be transmitted before receiving acknowledgements.

Error Control
Error control helps detect damaged frames and recover from transmission errors.

Error Detection

Techniques such as parity, checksum and CRC are used to detect errors.

Acknowledgement

The receiver sends ACK to indicate successful reception.

Negative ACK

NAK can indicate that a frame was received incorrectly and needs retransmission.

Retransmission

Lost or damaged frames may be retransmitted using ARQ mechanisms.

Sequence Numbers

Help identify frames and maintain the correct order during retransmission.

Timeout

If an expected acknowledgement does not arrive within a specified period, retransmission may occur.
