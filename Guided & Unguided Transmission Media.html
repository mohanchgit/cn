Transmission Media
Transmission media provides the physical path through which data signals travel from sender to receiver.
Category 1

Guided Media

Signals travel through a physical medium such as copper cable or optical fiber.

Category 2

Unguided Media

Signals propagate through air or free space using electromagnetic waves.

Main Goal

Communication

Carry information from a transmitting device to a receiving device.

Guided vs Unguided Media
Comparison of wired and wireless transmission media.
Feature Guided Media Unguided Media
Physical Path Uses a physical cable Uses air/free space
Examples Twisted pair, coaxial, fiber Radio, microwave, infrared
Mobility Limited High
Installation Requires cable deployment Does not require physical cable
Interference Depends on cable type More susceptible to environmental interference
Security Physical access is generally required Signals may be intercepted over the transmission area
Mobility Applications Less suitable Highly suitable
Key Concept: Guided = Signal follows a physical path   |   Unguided = Signal travels through free space
