1. What is Process-to-Process Delivery?

Process-to-process delivery is the responsibility of the Transport Layer to deliver data from a specific application process on the source computer to the correct application process on the destination computer.

Simple idea:
IP address identifies the computer.
Port number identifies the application/process.

Example

Suppose your computer accesses a web server: 

Client Computer
IP: 192.168.1.10
Port: 50000
       |
       | Internet
       ↓
Web Server
IP: 142.250.195.14
Port: 443

The IP addresses identify the two computers, while port numbers identify the communicating processes.

5. Multiplexing and Demultiplexing

Multiplexing

Multiple applications on a host can send data through the Transport Layer. The Transport Layer combines these data streams for delivery.

Browser → Port 50001
Email → Port 50002
Video Application → Port 50003

All of them can use the same network connection.

Demultiplexing

When data reaches the destination, the Transport Layer examines the destination port and delivers the data to the correct application.

Multiplexing: Many processes → Transport Layer

Demultiplexing: Transport Layer → Correct process

6. Elements of Transport Protocols

Important elements of transport protocols include:

Element Purpose
Addressing Identifies source and destination processes using ports
Multiplexing Allows multiple processes to use the transport service
Demultiplexing Delivers received data to the correct process
Segmentation Breaks application data into smaller units
Reassembly Combines segments back into the original data
Connection Management Establishes and terminates connections
Flow Control Prevents a fast sender from overwhelming a slow receiver
Error Control Detects and handles lost or corrupted data
Congestion Control Controls traffic when the network becomes congested
Ordered Delivery Ensures data arrives in the correct order

9. Flow Control

Flow control prevents a fast sender from sending more data than the receiver can handle.

Example:
Sender = 1 Gbps
Receiver = 100 Mbps

Without flow control, the receiver's buffer may overflow.

TCP uses the Receive Window (rwnd) to implement flow control.

10. Error Control

Error control ensures that data is delivered correctly despite packet loss or corruption.

  • Checksum
  • Sequence numbers
  • Acknowledgments
  • Retransmission
  • Timeout mechanism
If a segment is lost, TCP can retransmit the missing data.

11. Congestion Control

Congestion occurs when too much traffic is present in the network.

TCP uses mechanisms such as:

  • Slow Start
  • Congestion Avoidance
  • Fast Retransmit
  • Fast Recovery
Flow Control: Protects the receiver.
Congestion Control: Protects the network.

16. Interview Questions – Quick Revision

Q1. What is process-to-process delivery?

It is the delivery of data from a specific process on the source host to the corresponding process on the destination host using port numbers.

Q2. Why are port numbers required?

Because a computer can run multiple network applications simultaneously. Port numbers identify the correct application/process.

Q3. What is the difference between IP address and port?

An IP address identifies the host, while a port number identifies the process/application running on that host.

Q4. What is multiplexing?

Multiplexing allows multiple application processes to send data through the same transport layer.

Q5. What is demultiplexing?

Demultiplexing delivers received transport-layer data to the correct application using port information.

Q6. What is a socket?

A socket is an endpoint of communication commonly represented as an IP address and port number.

Q7. TCP or UDP – which is faster?

UDP generally has lower protocol overhead and can be faster for applications where reliability is handled by the application or where low latency is more important.

Q8. What is flow control?

Flow control prevents a sender from overwhelming the receiver.

Q9. What is congestion control?

Congestion control manages the sending rate to reduce network congestion.

Q10. What is segmentation?

Segmentation divides application data into smaller transport-layer units for transmission.
