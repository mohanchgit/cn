Error Detection and Correction

Data Link Layer | Error Control | Reliable Data Communication

📡 What is an Error?

During data transmission, bits may change because of noise, interference, attenuation, or other transmission problems.

For example:

Sender transmits: 10110010

Receiver gets: 10100010

One bit has changed.

🔍 Error Detection vs Error Correction

1 Error Detection

Determines whether an error has occurred during data transmission.

Example: Parity, Checksum and CRC

2 Error Correction

Determines the presence and location of certain errors and allows the receiver to recover the original data.

Example: Hamming Code

1️⃣ Parity Check

A parity bit is an additional bit added to binary data to make the number of 1s either even or odd.

Even Parity: Total number of 1s must be even.

Odd Parity: Total number of 1s must be odd.

3️⃣ Checksum

A checksum is calculated from blocks of data. The resulting value is transmitted along with the data.

The receiver performs a similar calculation and compares the result to determine whether the data has been corrupted.

4️⃣ CRC – Cyclic Redundancy Check

CRC is a powerful error-detection technique widely used in computer networks and digital communication.

CRC treats the data as a binary polynomial and performs division using a generator polynomial.

Basic Idea:

Data + Generator Polynomial
↓
Binary Division
↓
Remainder = CRC

🔢 CRC Example Structure

Original Data

1101011011

Generator

10011

Transmitted Frame

DATA + CRC

5️⃣ Hamming Code

Hamming Code is an error-correcting technique that adds redundant parity bits at specific positions.

The receiver uses the parity checks to calculate a syndrome that identifies the position of certain errors.

Important: Hamming code can detect and correct a single-bit error under the standard single-error-correction configuration.

📍 Hamming Code Bit Positions

Position 1 2 3 4 5 6 7
Bit Type P1 P2 D1 P4 D2 D3 D4
Binary Position 001 010 011 100 101 110 111

🧪 Hamming Code Error Locator

Enter the parity-check results P4 P2 P1. The resulting binary value identifies the error position.

Example: 101₂ = Position 5.

🎯 Easy Way to Remember

  • Parity: Count the number of 1s.
  • Two-Dimensional Parity: Check rows and columns.
  • Checksum: Add data blocks and verify the result.
  • CRC: Use binary polynomial division.
  • Hamming Code: Use parity positions to locate certain errors.
