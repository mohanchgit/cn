Network Topologies
A network topology describes how network devices and communication links are physically or logically arranged.
Physical Topology

Physical Arrangement

Describes the actual placement of cables, devices and network equipment.

Logical Topology

Data Flow

Describes how data moves between devices regardless of physical layout.

Common Types

Bus • Star • Ring • Mesh

Other common forms include Tree and Hybrid topologies.

Main Topologies: Bus, Star, Ring, Mesh, Tree and Hybrid

RJ-45 Connector
RJ-45 is commonly associated with Ethernet twisted-pair cabling.

RJ-45

Common connector used with Ethernet twisted-pair cables.

Pins

An 8-position modular interface is commonly used for Ethernet twisted-pair connections.

Cable

Commonly used with Cat5e, Cat6 and related twisted-pair Ethernet cables.

Application

PCs, switches, routers, patch panels and Ethernet wall outlets.

Remember: Ethernet + Twisted Pair + Modular Connector → RJ-45
BNC Connector
BNC is a bayonet-style connector commonly associated with coaxial cabling.

BNC

Bayonet-style connector used with coaxial cable.

Cable Type

Coaxial cable.

Connection

Twist-and-lock bayonet mechanism provides a secure connection.

Applications

Legacy Ethernet, video systems, test equipment and RF applications.

Key Point: BNC → Coaxial Cable → Bayonet Connection
Fiber-Optic Connectors
Fiber connectors provide precise alignment between optical fibers.

SC

Square-shaped push-pull connector commonly used in fiber systems.

ST

Bayonet-style connector historically common in fiber installations.

LC

Small-form-factor connector commonly used in high-density fiber systems.

Fiber Transmission

Data is transmitted as pulses of light through the optical fiber.

Network Topologies & Connectors — Summary
Topology defines network arrangement, while connectors provide physical interfaces between cables and network equipment.
Topic Key Concept Examples
